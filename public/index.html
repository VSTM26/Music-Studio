How It Works

Simple enough for normal users

01

Download the app

Install Music Studio on the user’s own machine instead of sending them into a remote browser or VM.

02

Sign into YouTube in their browser

Music Studio imports the local browser session so protected videos and likes can use the user’s real credentials.

03

Choose a folder and download

Paste links or pull likes, then save finished files right into the folder the user picked.

Why This Version
